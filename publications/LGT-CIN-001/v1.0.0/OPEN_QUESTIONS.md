# OPEN QUESTIONS

The following are post-v1.0 implementation/profile questions rather than blockers to the stable normative baseline:

- Should a future conformance profile standardize interoperable readiness-envelope fields?
- Which maturity properties should be mandatory transfer metadata between LGT components?
- What reference conformance corpus should test temporal change, contradiction, correction, and anti-self-reinforcement?
- Should consequence classes be standardized in a separate implementation profile rather than CIN itself?
- How should low-frequency, long-duration continuity be tested without prescribing universal time thresholds?

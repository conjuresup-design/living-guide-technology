# RELEASE NOTES

## LGT-CIN-001 v1.0.0 - Stable Baseline Candidate

v1.0.0 is the consolidation release for Continuity Intelligence.

The normative architecture established through v0.1.0-v0.9.0 has been reviewed as a complete system rather than extended with another conceptual layer. The release preserves the core discipline that continuity may deepen understanding while remaining evidence-bounded, temporally accountable, corrigible, authorization-respecting, falsifiable, and compatible with genuine member change.

Human DOCX/PDF parity QA remains the promotion gate.

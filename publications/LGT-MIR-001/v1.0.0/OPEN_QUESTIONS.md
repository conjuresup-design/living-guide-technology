# OPEN QUESTIONS

No unresolved major normative domain is identified for v1.0.0.

Post-release questions should be captured as implementation evidence rather than immediately expanding normative scope:
- Do real implementations expose any ambiguity between reflective salience and evidentiary confidence?
- Are member-control and invitation boundaries practically demonstrable across conversational and interface implementations?
- Do cross-domain implementations preserve source and dependency distinctions under scale?
- Does conformance testing reveal any architectural gap not covered by the stable requirements?

# RELEASE NOTES

## LGT-CMP-001 v1.0.0 - Stable

LGT-CMP-001 **Companion Before Oracle** is now the first stable CMP publication.

The publication contains 14 normative sections and 1,008 numbered subsections governing the companion relationship from formation and zero-history interaction through continuity, familiarity, adaptation, agency, anti-coercion, relational expression, contextual permission, transparency, failure and recovery, conformance governance, portability, reset, and termination.

Stable promotion preserves the exact normative content that passed final human QA in v1.0.0-RC1. Only release metadata changed during this promotion.
